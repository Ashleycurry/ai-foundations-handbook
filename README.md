# AI 基础手册

[中文](README.md) | [English](README-English.md)

本仓库用于整理人工智能基础相关的课程资料、学习笔记与配套代码，覆盖数学基础、机器学习、深度学习和大模型应用四个板块。当前仓库处于初始化阶段，目录骨架已经搭建完成，内容会持续沉淀到 `docs/`、`notes/` 与 `src/` 中。

## 目录结构

```text
ai-foundations-handbook/
├── README.md
├── README-English.md
├── docs/            # 课程课件、PDF / DOCX 资料
├── notes/           # Markdown 学习笔记与知识总结
└── src/             # 配套示例代码与练习
```

## 内容规划

### 一、数学与基础理论

- 线性代数：向量、矩阵运算、特征值与特征向量。
- 概率统计：随机变量、常见分布、参数估计与假设检验。
- 微积分与优化：梯度、导数、凸优化与数值计算方法。

### 二、机器学习

- 监督学习与无监督学习的基本范式。
- 线性回归、逻辑回归、决策树、集成学习、聚类等经典算法。
- 特征工程、交叉验证与模型评估指标。
- 过拟合与正则化、偏差与方差权衡。

### 三、深度学习

- 神经网络结构、前向传播与反向传播。
- 卷积神经网络、循环神经网络与 Transformer。
- 训练技巧：初始化、归一化、学习率调度与正则化。
- 常见任务的模型设计与调参思路。

### 四、大模型与应用

- 预训练、微调与提示工程的基本概念。
- 向量检索与检索增强生成（RAG）。
- 模型推理部署与工程化落地的常见方案。

## 使用方式

- `docs/` 中的资料按主题编号命名，例如 `001-xxx.pdf`。
- `notes/` 中的笔记与 `docs/` 中的资料保持同名编号，便于对照阅读。
- `src/` 中的代码按章节建立子目录，示例代码尽量保持可独立运行。
- 笔记与代码中的关键结论建议标注来源，便于后续复核。
