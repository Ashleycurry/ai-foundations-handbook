# AI 基础手册

[中文](README.md) | [English](README-English.md)

本仓库用于整理人工智能基础的学习笔记，内容按主题分册组织，依次覆盖开篇导论、数学基础、机器学习、人工神经网络、深度学习与深度学习框架六个板块。目前已完成并校对 000～015 共 16 篇，均为中文撰写，公式用 LaTeX 排版，可直接在 GitHub 上渲染，每篇末尾附有名词汇总表。

## 目录结构

```text
ai-foundations-handbook/
├── README.md
├── README-English.md
├── docs/                            # 课程课件、PDF / DOCX 资料
└── notes/
    ├── 000-开篇/                     # 导论与技术路线
    ├── 001-数学基础/                 # 线性代数、概率论、数理统计、最优化、信息论、形式逻辑
    ├── 002-机器学习/                 # 从概论到降维的九种经典方法
    ├── 003-人工神经网络/             # 神经元、感知器与网络结构
    ├── 004-深度学习/                 # 深度网络与训练技巧
    └── 005-深度学习框架下的神经网络/ # 框架实现与工程实践
```

## 使用方式

- `docs/` 中的资料按主题编号命名，例如 `001-xxx.pdf`。
- `notes/` 按板块分目录，笔记文件名为「编号-板块-主题」，便于排序与检索。
- 笔记中的公式用 LaTeX 书写，GitHub 页面可直接渲染；若在本地查看，请使用支持数学公式的 Markdown 编辑器（如 VS Code + Markdown Preview Enhanced）。
- 正文尽量以纯文本符号代替行内公式，仅保留少量块级公式，便于在任意终端里阅读。
