# AI 基础手册

[中文](README.md) | [English](README-English.md)

本仓库用于整理人工智能基础的学习笔记，内容按主题分册组织，依次覆盖开篇导论、数学基础、机器学习、人工神经网络、深度学习与深度学习框架六个板块。目前 000～027 共 28 篇已全部完成，并逐篇复核过公式、算例与交叉引用；全部为中文撰写，公式用 LaTeX 排版，可直接在 GitHub 上渲染，每篇末尾附有名词汇总表。

## 目录结构

```text
ai-foundations-handbook/
├── README.md
├── README-English.md
├── docs/                            # 课程课件、PDF / DOCX 资料
└── notes/

    ├── 001-数学基础/                 # 线性代数、概率论、数理统计、最优化、信息论、形式逻辑
    ├── 002-机器学习/                 # 从概论到降维的九种经典方法
    ├── 003-人工神经网络/             # 神经元、感知器与网络结构
    ├── 004-深度学习/                 # 深度网络与训练技巧
    └── 005-深度学习框架下的神经网络/ # 框架实现与工程实践
```

## 笔记索引

笔记按「板块 - 编号」组织，文件名形如 `007-机器学习概论：假设空间、泛化误差与模型评估.md`，冒号前是主题、冒号后是副标题。每篇末尾附有名词汇总（名称 / 英文全称 / 英文缩写 / 简短介绍）。

建议按编号顺序阅读：先看 000 建立整体印象，再用 001～006 打牢数学地基，然后进入 007～015 的经典机器学习算法，接着是 016～021 的神经网络结构，最后是 022～027 的深度学习。每篇正文中还穿插了以“新手提示”开头的引用块，专门解释容易卡住的术语与公式含义。

## 使用方式

- `docs/` 中的资料按主题编号命名，例如 `001-xxx.pdf`。
- `notes/` 按板块分目录，笔记文件名为「编号-主题：副标题」。
- 笔记中的公式用 LaTeX 书写，GitHub 页面可直接渲染；若在本地查看，请使用支持数学公式的 Markdown 编辑器（如 VS Code + Markdown Preview Enhanced）。
- 正文尽量以纯文本符号代替行内公式，仅保留少量块级公式，便于在任意终端里阅读。
- 复核以三条为准：公式可以逐项验算，结论与定义有明确出处，编号与交叉引用指向正确的笔记。
